# Nightfox theme data

Dayfox and Nightfox are derived from [EdenEast/nightfox.nvim](https://github.com/EdenEast/nightfox.nvim), pinned at revision `4dacd3f0185a2227bdf3b6c0975a8f0bf87cac9a`.

Sources at that immutable revision:

- [Dayfox TextMate theme](https://github.com/EdenEast/nightfox.nvim/blob/4dacd3f0185a2227bdf3b6c0975a8f0bf87cac9a/extra/dayfox/dayfox.tmTheme)
- [Nightfox TextMate theme](https://github.com/EdenEast/nightfox.nvim/blob/4dacd3f0185a2227bdf3b6c0975a8f0bf87cac9a/extra/nightfox/nightfox.tmTheme)
- [Dayfox palette](https://github.com/EdenEast/nightfox.nvim/blob/4dacd3f0185a2227bdf3b6c0975a8f0bf87cac9a/lua/nightfox/palette/dayfox.lua)
- [Nightfox palette](https://github.com/EdenEast/nightfox.nvim/blob/4dacd3f0185a2227bdf3b6c0975a8f0bf87cac9a/lua/nightfox/palette/nightfox.lua)
- [MIT license](https://github.com/EdenEast/nightfox.nvim/blob/4dacd3f0185a2227bdf3b6c0975a8f0bf87cac9a/LICENSE)

The JSON files preserve the TextMate scopes and settings; unused metadata and scope labels were removed. Theme names were corrected from the upstream exporter’s stale Catppuccin metadata. Astro supplies each theme's light/dark type. Site CSS uses the same revision's palette values.
